## 测试过程中发现并修复的问题
1. 迷雾过亮过平、视野过小 → 调暗雾色、视野 118→140px、柔边加宽。
2. 萤火虫光晕在雾中显示为灰色圆盘 → 改为径向渐变精灵。
3. 漂浮雾团在视野内仍有 25% 底透明度，遮住角色 → 改为随雾浓度线性变化。
4. 祭坛第三个符文基座被方尖碑完全遮挡 → 移到前方中央，并补充碰撞。
5. 移动端竖屏任务卡与「行囊」按钮重叠 → 窄屏下任务卡宽度自适应。
6. 移动端横屏快捷栏压在角色身上 → 矮屏下快捷栏回到底部。
7. 结局文字在明亮树冠上可读性差 → 加深中央背景。
