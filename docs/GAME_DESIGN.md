# Lost in the Mist：迷雾拾荒者 — 游戏设计文档（v2 生存版）

> v1「探索版」的设计（固定任务链的森林探索）保留在 Git 标签 `v1.0-explore`。
> v2 把它升级为开放世界生存游戏：机制参考《饥荒》一类生存游戏的设计思路，**世界观、角色、美术、音效、名称、界面全部原创**。

## 1. 定位
- **类型**：2D 俯视角开放世界生存
- **核心体验**：探索 → 采集 → 制作 → 建造 → 生存过夜 → 战斗 → 成长
- **节奏**：一天 = 8 分钟（白天 3.8 分钟、黄昏 1.1 分钟、夜晚 2.1 分钟、黎明 1 分钟）
- **失败**：永久死亡。死亡后存档清除，世界重新开始，显示存活天数与死因
- **长线目标**：保留 v1 的祭坛剧情。制作三枚月光符文唤醒北方祭坛，驱散迷雾；之后可以继续生存

## 2. 生存属性（`systems/survival.ts`）
| 属性 | 上限 | 下降 | 归零后果 | 恢复 |
|---|---|---|---|---|
| 生命 | 150 | 受伤、饥饿、寒冷、疯狂 | 死亡 | 食物；吃饱、暖和、精神好时缓慢回复 |
| 饥饿 | 150 | 0.26/秒（约 1.2 天从满到空） | 每秒 −1.5 生命，移速 −15% | 食物 |
| 精神 | 200 | 夜晚 −0.18/秒，黑暗 −0.6/秒，下雨，吃生肉或生蘑菇 | 每秒 −0.4 生命 | 篝火旁、白天、烤蘑菇、雾露、药水、读石碑 |
| 体温 | −10～75° | 趋近「环境 + 热源 + 装备保暖」 | 低于 2° 冻伤，高于 68° 过热 | 篝火、火把、护甲 |

环境温度：白天约 24°，夜晚约 5°，下雨再低约 9°。

## 3. 昼夜与黑暗（`systems/time.ts`）
- 光照等级在白天 → 黄昏 → 夜晚 → 黎明之间平滑变化；黄昏偏暖橙，黎明偏粉。
- **夜间视野只剩光源周围**：篝火（半径 70～220，随燃料变化）、火把 175、萤火灯笼 235、发光蘑菇、已唤醒的祭坛。
- **黑暗机制「雾噬」**：夜里站在光照外，1.2 秒后出现警告与耳语，4 秒后每 2.2 秒受到 28 点伤害。
- 低精神时：屏幕边缘泛紫，出现游荡的黑影和耳语。

## 4. 天气（`systems/weather.ts`）
从第 2 天左右开始随机降雨（持续 90～210 秒，间隔 400～900 秒）。下雨时：雨丝和水面涟漪、环境变暗、体温下降、精神下降、篝火燃烧加快 60%、树木摇摆更明显、出现雨声。

## 7. 建造（`systems/building.ts`）
制作面板点「建造」→ 出现跟随的预览（键盘和触屏放在面朝方向，鼠标放在光标处，并吸附到格子）→ 绿色表示可放置，红色时会说明原因（水面、阻挡、离其他建筑太近、离树或资源太近、离边缘太近、离自己太近）→ E、点击或「放置」按钮确认，**这时才扣除材料** → Esc、右键或「取消」退出。建筑会阻挡通行，随存档保存，读档后恢复。

- **篝火**：初始燃料 120 秒，上限 240 秒；可以添加木头（+55）、树枝（+20）、干草（+14）；提供照明、取暖、精神恢复；能烹饪雾莓、生肉、萤光蘑菇；熄灭后可以重新添柴点燃。雾狼不会进入燃烧中篝火的光圈。
- **储物箱**：12 格，点击物品即可在背包和箱子之间转移。

## 9. 生物与战斗（`systems/creatures.ts`）
| 生物 | 生命 | 行为 | 掉落 |
|---|---|---|---|
| 雾兔 | 25 | 白天出现在草地，玩家靠近（120px 内）就逃跑 | 生肉 |
| 雾狼 | 100 | 第 2 天起在黄昏和夜晚成群出现（1～3 只，并伴随狼嚎）；在 260px 内主动追击；攻击前有 0.38 秒前摇（可以躲开）；不进入篝火光圈；天亮后离开 | 生肉 1～2 |

- 攻击：F 键、鼠标左键或触屏「攻击」按钮。冷却 0.55 秒，攻击距离约 50px，优先打面朝方向的目标；命中时有击退和受击闪白。
- 伤害：空手 10、火把 14、镐 18、斧 20、长矛 34。
- 玩家受伤时屏幕边缘泛红、画面震动；护甲按比例吸收伤害。

## 10. 旅程（长线引导）
1. **林间苏醒**：树枝 4、干草 4、燧石 2
2. **燧石与木头**：制作斧头，收集木头 4
3. **第一夜**：建造篝火，活到第 2 天
4. **萤火**：制作萤火灯笼
5. **月光矿脉**：制作镐，开采月光石 6
6. **符文之约**：制作月光符文 3
7. **森林祭坛**：找到祭坛，献上符文 → 迷雾散去的结局演出 → 继续生存
