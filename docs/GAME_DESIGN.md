# Lost in the Mist（迷雾拾荒者）— 游戏设计文档

## 1. 概述
- **类型**：2D 俯视角幻想森林探索 / 采集制作
- **平台**：桌面与移动端浏览器（键盘 + 触屏）
- **时长**：首通约 15–25 分钟
- **核心体验**：在浓雾中摸索 → 一点点点亮森林 → 理解森林的秘密 → 亲手让迷雾散去

## 2. 核心循环
探索（驱散迷雾）→ 发现资源 → 采集 → 制作工具/道具 → 解锁新区域与能力 → 推进任务 → 唤醒祭坛

## 3. 世界
固定种子生成的 96×72 瓦片森林（每格 32px，共 3072×2304px），每次游戏地形一致，存档只记录动态状态。

| 区域 | 位置 | 特征 | 资源 |
|---|---|---|---|
| 醒来的空地 | 南部中央 | 出生点、第一块石碑 | 灵木枝（密集） |
| 幽暗林 | 东部 | 深色苔地、发光蘑菇照明 | 萤光蘑菇 |
| 雾湖 | 西部（另有东北、西南小水塘） | 岸边芦苇、睡莲 | 雾铃草 → 雾露 |
| 岩地矿脉 | 西北 / 东北 | 石质地面、针叶树 | 月光石（需镐） |
| 森林祭坛 | 正北 | 圆形石台、方尖碑、三个符文基座 | — |

石径从出生点贯穿全图通往祭坛，并分叉到各区域；地图生成后做 BFS 校验，所有资源、石碑与祭坛都保证可步行到达。

## 4. 资源与物品
| 物品 | 来源 | 产量 | 重生 |
|---|---|---|---|
| 灵木枝 | 枯枝堆 | 1–2 | 90 秒 |
| 萤光蘑菇 | 萤光蘑菇丛 | 1–2 | 100 秒 |
| 雾露 | 雾铃草 | 1 | 90 秒 |
| 月光石 | 月光石矿（需灵木镐） | 2 | 120 秒 |

## 5. 制作
| 产物 | 配方 | 效果 |
|---|---|---|
| 萤火灯笼（唯一） | 灵木枝×3 + 萤光蘑菇×2 | 视野 140 → 235px，角色手提灯笼发光 |
| 灵木镐（唯一） | 灵木枝×4 + 雾露×2 | 可开采月光石 |
| 雾露药水 | 雾露×2 + 萤光蘑菇×1 | 25 秒内移速 +45%、视野 +60px |
| 月光符文 | 月光石×2 + 雾露×1 + 萤光蘑菇×1 | 唤醒祭坛需 3 枚 |

## 6. 任务链
1. **林间苏醒**：收集 5 灵木枝（教学：移动、采集）
2. **第一盏微光**：采集 2 萤光蘑菇，制作萤火灯笼（教学：制作，视野提升）
3. **湖畔的露水**：收集 2 雾露，制作灵木镐（工具门槛）
4. **月光矿脉**：开采 6 月光石（深入北方迷雾）
5. **符文之约**：制作 3 枚月光符文
6. **森林祭坛**：找到祭坛，献上符文 → 结局

引导：屏幕边缘的琥珀色箭头指向当前任务区域，地图上以虚线圈标出；HUD 左上角实时显示目标进度。

## 7. 迷雾系统
- 16px 精度探索网格。未探索 = 浓雾（93%），探索过但不在视野 = 薄雾（42%），视野内 = 清晰，边缘柔和渐变。
- 低分辨率雾图平滑放大 + 飘动雾团精灵 + 屏幕空间暗光照（玩家、蘑菇、晶石、祭坛为光源）。
- 小地图 / 大地图只显示探索过的地形。
- 结局时迷雾在 3 秒内全部褪去，之后可自由漫步。

## 8. 辅助内容
- 5 块古老石碑，阅读后获得背景故事（结局统计「阅读石碑 x/5」）。
- 结局统计：旅程时长、探索度、拾取材料数、阅读石碑数。

## 9. 操作
| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | WASD / 方向键（Shift 慢步） | 左下浮动摇杆（按下位置即摇杆中心） |
| 采集 / 互动 | E / 空格 | 右下「采集」按钮（文字随目标变为阅读/献上） |
| 行囊（背包 + 制作） | B / Tab | 右上「行囊」 |
| 地图 | M | 右上「地图」 |
| 使用药水 | Q | 「药」按钮 |
| 暂停 | Esc / P | 右上「暂停」 |

## 10. 存档
- LocalStorage `litm.save.v1`：位置、背包、累计采集/制作、任务进度、资源重生时刻、已读石碑、游戏时长、迷雾探索度（行程编码）、结局状态。
- 自动存档时机：每 20 秒、任务完成、制作、暂停、返回菜单、页面隐藏/关闭。
- 设置单独保存在 `litm.settings.v1`。

## 11. 技术架构
```
src/
  engine/   math（随机/噪声）· input（键盘+摇杆）· audio（WebAudio 合成）
  art/      painters（程序化手绘资源）· manifest（资源表 + 正式 PNG 替换接口）
  world/    map（地图生成、碰撞格）· ground（地面烘焙）· fog（迷雾）
  game/     data（物品/配方/任务，纯数据）· state（背包/制作/任务/存档）· game（状态机、模拟、渲染）
  ui/       ui（DOM 界面）
```
游戏逻辑（data/state）不依赖渲染引擎，可直接迁移到 Phaser。
